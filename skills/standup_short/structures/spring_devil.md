# 弹簧魔鬼

执念被压下 → 弹起 → 再压 → 更猛烈弹起 → 爆发。被压制的力量反复弹起，每次更猛烈。

## 骨架

执念出现 → 被压制 → 弹起 → 再被压制 → 猛烈弹起 → 爆发

## 分段标签

```
【执念】
角色的小小执念/想说的话（1 句立住）

【压制】
第一次被压下，弹起来一次（较轻）

【反弹】
再次被压，弹起更猛烈（加码）

【爆发】
压不住了，执念彻底爆发，主爆梗在此

【收尾】
一句话回扣，mini callback 再炸一次
```

## 写法要点

- 至少"压—弹"两轮，每轮弹起比上轮更猛烈、更离谱。
- 压制者要一本正经，角色越不自觉越好笑。
- 爆发就是全片最大的那一声笑，前面都在为它蓄力。

## 示例

【执念】开会时我满脑子都是"这方案行不通"。
【压制】领导问意见，我说"挺好的"，弹回来一句：预算谁出？
【反弹】我又咽回去，弹得更猛：客户根本不可能签字！
【爆发】领导再问，我拍桌而起："这方案是我上周被毙掉的那份！"
【收尾】领导沉默三秒：那你再改改。
