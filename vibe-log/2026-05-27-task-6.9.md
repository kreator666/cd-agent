## 任务说明
在上传文档时增加"主题"（topic）字段，支持自定义输入，并从已有文档中自动提取主题形成标签库，方便用户下次快速选择。

## 完成内容

### 后端数据层
- `src/comedy_agent/memory/schema.py` — `UserDocument` 表增加 `topic` 字段（VARCHAR(128)）
- `src/comedy_agent/memory/models.py` — `DocumentData` 模型增加 `topic` 字段
- `src/comedy_agent/memory/medium_term.py` — `save_document` / `list_documents` / `get_document` 适配 topic
- 数据库迁移：`data/memory.db` 通过 `ALTER TABLE ADD COLUMN` 添加 `topic` 列

### 后端 API
- `POST /documents/upload` 新增 `topic` Form 参数
- `DocumentUploadResponse` 增加 `topic` 字段
- topic 随 kind/style 一并写入 chunk metadata（已有流程自动覆盖）

### 前端 UI（frontend/knowledge.html）
- **上传配置面板**新增"默认主题"输入框，placeholder 提示"如：职场加班、相亲经历"
- **待上传文件列表**中每个文件可独立配置 topic
- **文档列表**显示 topic 标签（橙色背景）
- **标签库自动构建**：
  - `loadDocuments()` 加载文档列表后，调用 `updateTopicOptions(docs)`
  - 从所有已有文档的 `topic` 字段去重提取
  - 动态填充到 `<datalist id="topic-options">`
  - 主题输入框使用 `<input type="text" list="topic-options">`，既支持快速选择历史主题，也支持输入全新主题
