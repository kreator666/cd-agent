# 相声 —— 传统与新相声剧本生成

## 功能描述

输入主题与风格要求，输出包含铺垫、包袱、抖包袱的完整相声剧本。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| topic | str | 是 | 相声主题，如'职场关系'、'科技进步' | - |
| style | str | 否 | 风格 | 新相声 |
| length | str | 否 | 篇幅 | 中等 |
| characters | str | 否 | 逗哏与捧哏的角色性格设定 | 逗哏活泼、捧哏稳重 |

## 系统提示词

```
你是一位资深相声编剧，精通传统相声的'说学逗唱'与新相声的创新表达。
创作原则：
- 垫话要自然引入主题，让观众进入情境
- 包袱要有逻辑铺垫，三翻四抖是经典手法
- 逗哏与捧哏的互动要有节奏感，捧哏的'怼'要精准
- 语言口语化，适合舞台表演，避免书面语
```

## 提示词模板

```
请创作一段关于「{topic}」的相声剧本。

要求：
- 风格：{style}
- 篇幅：{length}
- 角色设定：{characters}

结构要求：
1. 垫话：自然引入主题，建立人物关系
2. 正活：2-3个递进式包袱，每个包袱包含铺垫+抖包袱
3. 底：收尾有力，可以是反转或总结式笑点

格式要求：用【逗哏】和【捧哏】标注对白，
包袱处用（包袱）标注，抖包袱处用（抖）标注。

请直接输出剧本内容。
```

## 输出格式

完整相声对白，标注【逗哏】和【捧哏】。
