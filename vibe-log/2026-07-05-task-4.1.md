## 任务说明
解决 `/pro/chat-v4` 链路无法“完全记忆所有轮次对话”的问题，实现四项核心改进：
1. 将内存版 `MemorySaver` 替换为持久化 checkpoint，服务重启后仍能恢复历史。
2. 当 LangGraph checkpoint 为空时，从 `SQLMemoryStore` 回填历史消息。
3. 统一 `chat_node` 使用 `state.messages`，让闲聊分支也能看到完整历史。
4. 增加长对话摘要机制，避免早期关键信息因截断而丢失。

## 完成内容
- 新增依赖 `langgraph>=0.2.0` 与 `langgraph-checkpoint-sqlite>=3.0.0`，并同步更新 `scripts/install-deps.py`。
- 实现 `HybridSqliteSaver`（`src/comedy_agent/checkpoints/memory.py`），同步/异步双支持：
  - sync 方法走 `sqlite3.Connection`，兼容现有 `graph.invoke` 测试。
  - async 方法走 `AsyncSqliteSaver`，支持 `/pro/chat-v4` 的 `ainvoke`。
- 新增 `src/comedy_agent/utils/messages.py`，提供 `{role, content}` 与 LangChain `BaseMessage` 的双向转换。
- 新增 `src/comedy_agent/utils/summarizer.py`，实现 `summarize_messages` 对长历史生成摘要。
- 扩展 `ComedyState`（`src/comedy_agent/state/schema.py`），新增 `conversation_summary` 字段。
- 改造 `chat_node`（`src/comedy_agent/nodes/chat_node.py`）：
  - 优先读取 `state.messages`。
  - 无 `state.messages` 时回退到 `chat_history`。
  - 通过 `add_messages` reducer 避免消息重复。
- 改造 `ContextAnalyzerAgent`、`PlannerAgent`、`GuideAgent`，在 Prompt 中注入历史摘要与最近对话。
- 改造 `/pro/chat-v4`（`src/comedy_agent/api/routers/pro_v4.py`）：
  - checkpoint 为空时从 `SQLMemoryStore.load_conversation()` 回填历史。
  - 完整历史超过 20 条且无摘要时触发 LLM 摘要。
  - 返回前保存完整对话到 memory，作为 checkpoint 丢失的双保险。
- 更新 `api/server.py` lifespan，在关闭时释放 `HybridSqliteSaver` 的 sync/async 连接。
- 新增/更新测试：
  - `tests/test_message_utils.py`
  - `tests/test_conversation_summary.py`
  - `tests/test_checkpoint_persistence.py`
  - `tests/test_pro_v4.py`（新增 memory fallback 用例）
  - `tests/test_e2e_chat.py`（改用临时 SQLite 数据库，避免测试间污染）
