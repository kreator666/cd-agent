# plus1 

## 喜剧手法速查（核心）

### 三大情境手法
- **弹簧魔鬼** — 被压制的力量反复弹起，每次更猛烈
- **雪球效应** — 小因→大果，效应自我增强
- **系列干扰** — 两条独立事件线索交叉碰撞

### 三大语言手法
- **换位** — 庄→俗（滑稽模仿）或 俗→庄（幽默）
- **反转** — 主宾对调，让对方自食其果
- **现成句式+荒谬** — 刻板语言表达荒谬内容

### 相声三翻四抖
- **三番（四抖）** — 反复铺垫，第三/四遍突然反转抖包袱

### 角色设计核心
- **单一执念型** — 人格被一个缺点主宰，反复出现不自知
- **系统性心不在焉** — 围绕中心思想的持续脱离现实，完全不觉察
- **无意识暴露** — 角色最可笑的话/动作，恰是TA最不自觉的瞬间




# plus2
# 脱口秀输出模板

> 适用：单人口述喜剧，5-20分钟。核心是"我"的视角 + 铺垫-反转节奏。

## 输出规格

### 结构规范

```
【脱口秀标题】

【开场 Hook】（钩子，30秒内抓住注意力）

【第一段：建立世界观】
铺垫内容 → 核心笑点
（2-3个铺垫-反转段落）

【第二段：深挖细节】
更多细节 → 更深层的笑点
（call back 到开场 hook）

【脆弱时刻】（可选，1处）
制造共鸣的真诚段落

【第三段：疯狂升级】
笑点密度加大，节奏加快
（3-4个快节奏段子）

【收尾 Call Back】
回归开场钩子，但用更荒谬的方式
```

## 创作步骤

### Step 1：确定核心主题句

一句话说清你想讲什么。问自己：这里有什么"生命的机械化"？

### Step 2：找三个故事/观察

脱口秀最好有具体细节。三个故事/观察点，形成递进。

### Step 3：设计铺垫-反转结构

```
铺垫 = 让观众往 A 方向想
笑点 = 揭示其实是 B 方向

铺垫要"真"——观众必须相信才能笑
反转要"快"——不要铺垫太久才反转
```

### Step 4：埋 Call Back

在第一段或第二段埋一个笑点素材，在结尾用更荒谬的方式调用。

## 手法清单（脱口秀优先）

| 手法 | 说明 |
|------|------|
|铺垫-反转|核心结构|
|Call back|前面埋的梗后面再抖|
|身份错位|我是X但我做了Y|
|逻辑滑坡|从一个正常前提推到荒谬结论|
|自我打击|先说一个观点然后自己反驳|
|细节堆叠|用超具体的细节制造荒谬|
|反向预期|观众以为你会说A，你说了B|
