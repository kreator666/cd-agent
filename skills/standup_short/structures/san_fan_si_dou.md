# 三番四抖

同一方向铺垫三次，第四次抖开。笑点 = 预期被加固到顶点后突然落空。

## 骨架

铺垫 → 第一番（建立预期）→ 第二番（强化）→ 第三番（加剧）→ 第四抖（翻转）

## 分段标签

```
【铺垫】
交代场景与人物，丢出包袱（1 句）

【三番】
同方向连铺三句，一句比一句笃定，
让观众预期锁死（每番半句到一句）

【爆梗】
第四抖：突然翻转，预期落空

【收尾】
一句话回扣，mini callback 再炸一次
```

## 写法要点

- 三句必须同向递进，不能换方向；每句更笃定、更具体。
- 第四抖要"意料之外、情理之中"——观众一愣之后觉得"确实如此"。
- 严禁无厘头：没想到且没道理的翻转不是包袱，是乱编。

## 示例

【铺垫】我闺蜜说她最近在练瑜伽。
【三番】第一天说拉伸特别舒服。第二天说老师夸她有天赋。第三天说她已经能倒立了。
【爆梗】第四天她妈来电话：你别在墙上练，那是我家贴的福字。
【收尾】她至今不知道，倒立那天邻居报了警。
