### 前端 UI 重构（frontend/knowledge.html）
- **上传配置面板**：
  - 种类下拉：通用 / 脱口秀 / 相声 / 小品 / 情景喜剧 / 漫才 / 日式短剧
  - 风格输入：`<input type="text" list="style-options">`，支持自定义输入（datalist 仅作建议）
  - 分块策略下拉：按段落（推荐）/ 按场景（剧本）/ 按对话（相声/小品）/ 按字幕（视频字幕）/ 固定大小
- **待上传文件列表**：选择文件后展示列表，每个文件可独立配置 kind/style/策略，支持删除
- **进度反馈**：点击"开始上传"后逐个处理，每个文件展示 4 个状态节点：
  - 上传中 → 解析中 → 分块中 → Embedding 入库
  - 完成标记绿色 ✓，当前节点高亮
- **文档列表增强**：每行展示文件名 + 种类标签 + 风格标签 + 分块策略标签 + 块数 + 状态
