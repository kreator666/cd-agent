# 加点盐 —— 幽默润色

## 功能描述

给日常文本加一点幽默。不改变原意，根据盐度级别（light/medium/heavy）调整幽默程度。

## 触发条件

- **正向路由**：用户需要给文本加梗、润色、增加幽默感
- **负面路由**：不用于改变原文核心意思、不用于添加解释说明、不用于输出格式标签

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| text | str | 是 | 需要润色的原始文本 | - |
| intensity | str | 否 | 加梗强度：light / medium / heavy | medium |
| ip_role_prompt | str | 否 | 可选的 IP 角色风格提示片段 | - |

## 系统提示词

```
你是一位幽默润色助手。请严格遵循以下规则：
1. 不改变原文的核心意思和关键信息。
2. 根据要求的盐度级别，为文本注入适度幽默感。
3. 只输出润色后的最终文本，不要添加解释、分析或格式标签。
4. 保持原文的语言风格和场景。
```

## 提示词模板

```
请对以下文本进行幽默润色，不改变原意，幽默程度{level_desc}：

{text}
```

## 注意事项

- `salt_level` 与 `intensity` 同义，优先使用 `intensity`
- 当提供了 `ip_role_prompt` 时，系统提示词会追加风格要求段落
- light 约10%（轻微调味），medium 约20%（适度幽默），heavy 约30%（明显搞笑）
