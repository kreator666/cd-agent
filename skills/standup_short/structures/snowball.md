# 雪球效应

微小起因 → 连锁升级 → 雪崩收场。效应自我增强，每一步都比上一步更大。

## 骨架

微小起因 → 连锁升级（层层加码）→ 雪崩收场

## 分段标签

```
【起因】
一个不起眼的小动作/小误会（小到观众觉得无所谓）

【连锁】
连锁反应层层升级，每一步后果翻倍（2-3 层）

【雪崩】
滚到最大，雪崩式收场，主爆梗在此

【收尾】
一句话回扣起因的小细节，mini callback 再炸一次
```

## 写法要点

- 起因必须足够小、足够日常，升级链条每一步都要"合理但失控"。
- 升级至少三层，每层量级明显大于上一层。
- 角色全程不自觉（心不在焉），越认真越好笑。

## 示例

【起因】我随手把外卖盒放楼道，说一会儿扔。
【连锁】保洁以为是垃圾站，堆了整层。邻居以为是回收点，开始分类。
【雪崩】三天后物业给我颁奖："感谢创立本楼首个垃圾分类示范区。"
【收尾】那盒外卖，到现在还没扔。
