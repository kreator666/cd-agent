## 任务说明
用户输入 `@排版 将结果排版，可以排成什么样的？` 时，排版 Skill 返回了参数提取提示文本（`请只输出合法的 JSON 对象` 等），完全不可读。需要修复参数解析兜底、优化提示词、增加平台说明与示例输出。

## 完成内容
- **AgentOrchestrator._extract_skill_args**: 增加提示文字污染检测 `_is_contaminated_value`，过滤 LLM 从 prompt 中复制出的指令文本（如 "请只输出合法的 JSON"、"不要有任何解释" 等），避免污染 Skill 的 `text` 参数。
- **LayoutSkill 意图识别**: 新增 `_is_consultation` / `_is_prompt_contamination`，对空文本、咨询句（"可以排成什么样"、"有哪些平台" 等）、提示污染文本统一返回平台帮助信息，而不是做形式化排版。
- **LayoutSkill 帮助信息**: 新增 `_platform_help()`，说明微信公众号/小红书/知乎/B站专栏四种平台的适用场景与特点，并给出使用示例。
- **LayoutSkill 提示词优化**: system prompt 明确禁止把提示文字当作正文输出，减少模型 "复制 prompt" 的概率。
- **ProWorkflowEngine._call_skill_direct**: `@排版` 调用时优先使用用户查询词，识别咨询意图后直接返回帮助信息；有正文和平台要求时把正文与要求一并传给 Orchestrator。
- **测试覆盖**: 更新 `test_skills_layout.py`、`test_agent_orchestrator.py`、`test_pro_workflow_skill_mapping.py`，新增提示污染过滤、空请求兜底、咨询帮助、pro_workflow 咨询路径等用例。
