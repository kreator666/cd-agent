# 短视频爆笑段子输出模板

> 适用：单人口播短视频，30 秒以内。核心是"快速铺垫 → 密集爆梗 → 干净收尾"。

## 输出规格

### 硬约束（全局，任何结构都必须遵守）

1. **时长 ≤ 30 秒**：中文口播正文约 100~150 字，绝不超过 300 字。
2. **爆梗密度**：1 个主爆梗，或 2~3 个连续小梗；不要平铺直叙。
3. **剧情完整但简短**：一条明确的剧情线，有头有尾。
4. **收尾必须 mini callback**：回扣前面埋下的一个小细节，再炸一次。
5. **结构标签**：用 `【】` 整行标签分段，标签后接该段正文。

### 故事结构

分段标签与骨架由所选故事结构决定（见 `structures/` 目录，每种结构一个文件）：

| key | 结构 | 骨架 |
|-----|------|------|
| setup_punchline | 铺垫-反转 | 建立预期 → 细节加固 → 一句话翻转 |
| san_fan_si_dou | 三番四抖 | 同方向铺垫三次 → 第四次抖开 |
| snowball | 雪球效应 | 微小起因 → 连锁升级 → 雪崩收场 |
| spring_devil | 弹簧魔鬼 | 执念被压 → 弹起 → 再压 → 更猛烈弹起 → 爆发 |
| reductio | 归谬滑坡 | 接受荒谬前提 → 一本正经推到极致 → 结论炸裂 |

structure=random 时从 5 个结构中随机选一个，只注入该结构的提示词。

## 创作步骤

### Step 1：定核心反差/冲突

按所选结构找到全片的"那一声笑"：反转点、第四抖、雪崩点、爆发点或荒谬结论。

### Step 2：铺垫要"真"、要"快"

- 铺垫必须是观众一秒就能相信的日常场景。
- 前 5 秒必须出现抓人的细节或冲突，禁止慢热。

### Step 3：爆点设计

```
主爆梗一个就够，炸得响；
或者用 2~3 个连续小梗形成"连珠炮"节奏。
意外但必须合理——严禁无厘头。
```

### Step 4：收尾收口

一句话结束，必须回扣前面一个小细节做 mini callback（呼应再炸一次）。

## 手法清单（短视频优先）

| 手法 | 说明 |
|------|------|
| 铺垫-反转 | 核心结构，30 秒内只允许一个主反转 |
| 连珠小梗 | 2~3 个连续小爆点，节奏快过深度 |
| 身份错位 | 我是X但我做了Y，一秒建立 |
| 逻辑滑坡 | 从正常前提一步推到荒谬结论 |
| 重复升级 | 同一动作反复出现，逐级加码 |
| mini call back | 收尾一句话回扣爆梗 |

## 节奏参考

```
0-5 秒：铺垫抓人（出现一个具体细节或冲突）
5-15 秒：结构推进（按所选结构铺/压/滚/推）
15-25 秒：爆梗引爆（主爆梗炸开）
25-30 秒：收尾收口（mini callback）
```

## 字数红线

```
正文总字数（不含标签）：100~150 字为宜
绝对上限：300 字
超过 300 字 = 失败，必须删减
```
