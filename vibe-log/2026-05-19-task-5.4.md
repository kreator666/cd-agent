## 任务说明
建立剧本质量、检索相关性、模型输出的自动化评估指标与回归测试框架，支持在 CI/CD 流水线中快速运行。

## 完成内容
- 新增 `evaluation/` 模块体系：
  - `script_quality.py` —— 剧本质量评估器（不依赖 LLM）：
    - 笑点密度：检测笑关键词 + 感叹号/问句密度
    - 对话占比：冒号引导行 + 引号包裹内容检测
    - 结构完整性：起承转合关键词检测 + 段落数加分
    - 词汇多样性：unique/total ratio
    - 口语化程度：口语词密度
    - 长度适中性：按剧本类型（脱口秀/相声/小品/情景喜剧/段子）有不同期望区间
    - 可读性：平均句长评估
    - 支持自定义权重与综合评分
  - `retrieval_quality.py` —— 检索质量评估器：
    - Recall@K、Precision@K、MRR、NDCG@K
    - 支持单条查询与批量评估
  - `model_quality.py` —— 模型输出质量评估器：
    - 格式合规（markdown/json/dialogue 检测）
    - 重复率检测（连续重复句子 + 子串相似度）
    - 结构完整性（段落数）
    - 长度适中性
    - 笑点/对话信号检测
  - `regression.py` —— 回归测试框架：
    - `EvaluationSuite` / `TestCase`：从 JSON 加载测试用例
    - `run_suite()`：自动分发到对应评估器并生成报告
    - 支持阈值断言（`expected.min_score`）
  - `report.py` —— 评估报告：
    - `EvaluationReport`：支持通过率、平均得分、按类型汇总
    - 导出 JSON / Markdown 格式
- CLI 集成：新增 `evaluate` 子命令
  - `evaluate script --content "..." --type standup`
  - `evaluate output --content "..." --format markdown`
  - `evaluate suite --file suite.json`
- API 集成：新增评估端点
  - `POST /evaluate/script` —— 剧本质量评估
  - `POST /evaluate/output` —— 模型输出质量评估
- 测试：
  - 新增 `tests/test_evaluation_core.py`，覆盖 ScriptQualityEvaluator、RetrievalEvaluator、ModelOutputEvaluator、EvaluationSuite、run_suite、EvaluationReport，共 23 个用例
  - 更新 `tests/test_api_server.py`，新增 2 个评估端点测试
  - 全量测试 338 passed, 7 skipped，无回归
