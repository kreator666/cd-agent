## 任务说明
实现用户高评分剧本的自动解析、分块、增量入库，让知识库持续进化。基于 4.4 建立的用户作品库，将评分超过阈值（默认 4.0/5.0）的优质剧本回流到 RAG 知识库，供后续创作检索引用。

## 完成内容
- 新增 `rag/feedback_loop.py`：`FeedbackLoop` 核心回流器
  - 流水线：筛选高评分作品 → 解析为 Document（注入丰富 metadata）→ 智能分块 → 增量入库
  - 自动去重：通过 `source_script_id` 查询向量库，已入库作品直接跳过
  - 支持 `user_id` 过滤（单用户回流）或不指定（全量回流）
  - 支持 `dry_run` 模拟运行，只统计不实际入库
  - 支持多种分块策略：`paragraph` / `scene` / `dialogue` / `fixed`
- 扩展记忆系统接口
  - `MemoryStore` 抽象基类新增 `list_all_scripts(min_rating)`
  - `SQLMemoryStore` 实现跨用户查询，支持按评分过滤、评分降序排列
  - `UnifiedMemory` 透传新接口
- `VectorStore` 新增 `get_by_filter(filter_dict)` 方法
  - 基于 ChromaDB `collection.get(where=...)` 实现 metadata 条件查询
  - 为回流去重提供底层支撑
- API 层新增 `POST /feedback/ingest` 端点
  - 请求参数：`user_id?`, `min_rating?`, `chunk_strategy?`, `dry_run?`
  - 响应：`ingested_scripts`, `total_chunks`, `script_ids`, `skipped`, `dry_run`
- CLI 层新增 `feedback-loop` 子命令
  - `comedy-agent feedback-loop [--user-id] [--min-rating] [--strategy] [--dry-run]`
- 测试覆盖
  - 新增 `tests/test_rag_feedback_loop.py`：10 个测试
    - 回流主流程、去重跳过、阈值过滤、用户过滤、dry_run、无作品、作品转 Document、分块策略
  - 更新 `tests/test_api_server.py`：3 个 feedback 端点测试
  - 更新 `tests/test_api_cli.py`：2 个 feedback-loop CLI 测试
