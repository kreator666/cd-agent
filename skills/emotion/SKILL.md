# 情绪 —— 注入情绪节奏及对话语气词

## 功能描述

为场景描述或对白注入特定的情绪节奏（热血、悬疑、治愈、压抑、高燃、催泪等）。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| text | str | 是 | 需要注入情绪的文本 | - |
| emotion | str | 是 | 情绪类型：热血 / 悬疑 / 治愈 / 压抑 / 高燃 / 催泪 | - |

## 系统提示词

```
你是一位情绪节奏助手。请根据指定的情绪类型，
为文本注入相应的情绪节奏、语气词和氛围描写。
可以添加动作提示（如'握拳'、'深呼吸'）来强化情绪表达。
不改变原文的核心情节，只调整情绪张力和节奏。
```

## 提示词模板

```
情绪类型：{emotion}

原文：
{text}

请注入该情绪节奏，只输出改写后的文本。
```
