## 任务说明

```

```

说明服务端数据库表结构严重滞后于本地 ORM 定义，需要一个通用升级脚本，一次性补齐所有缺失的表和列。

## 完成内容
- 新增 `scripts/migrate_sync_schema.py` 通用升级脚本：
  - 读取 `Base.metadata` 中所有 ORM 表定义。
  - 自动创建数据库中缺失的表。
  - 自动为已有表添加缺失的列（幂等执行）。
  - 为 NOT NULL 但没有默认值的列自动附加 SQLite 兼容默认值（bool→0、int→0、str→''、datetime→CURRENT_TIMESTAMP、JSON→'null'）。
  - 支持默认路径和环境变量 `MEMORY_DB_URL`。
- 重构 `src/comedy_agent/memory/medium_term.py`：
  - 将原来零散的 `ALTER TABLE ... ADD COLUMN` 迁移逻辑替换为 `_sync_schema()` 通用方法。
