## 任务信息

## 任务说明
根据现有架构，在调用模型时增加计费功能，按用户维度记录在费用表中，并在"我的"页面增加"消费明细"入口。

## 完成内容
### 数据层
- 新增 `TokenConsumptionRecord` 表（`token_consumption_records`）及 Pydantic 模型 `TokenConsumptionData`。
- 在 `MemoryStore` 抽象基类、`SQLMemoryStore`、`UnifiedMemory` 中实现 `save_consumption_record` 与 `list_consumption_records`。
- 在 `UserProfile` 中补充 `consumption_records` 关系。

### 模型层
- 新建 `src/comedy_agent/models/usage_tracker.py`：
  - `UsageCallbackHandler`：通过 LangChain callback 在 LLM 调用结束时捕获 Token 用量。
  - 支持 OpenAI 兼容格式、`usage_metadata`、Ollama 等兜底解析。
  - 使用 `contextvars` 累计同一次请求中的多次模型调用。
- 修改 `src/comedy_agent/models/factory.py`：
  - `get_model()` 与 `get_model_with_fallback()` 返回的模型自动挂载 `UsageCallbackHandler`。

### API 层
- 新建 `src/comedy_agent/api/billing.py`：
  - `start_usage_tracking()` / `charge_model_usage()`：读取累计用量、扣减余额、写入消费记录。
- 改造以下入口为按真实 Token 用量计费：
  - `POST /chat`
  - `POST /skills/standup`、`/skills/sketch`、`/skills/manzai`、`/skills/japanese-sketch`
  - `POST /salt`
  - `POST /speed/polish`
  - `POST /pro/generate`
  - `POST /pro/chat`
  - `POST /ip-roles/{role_id}/try`
- 在 `src/comedy_agent/api/routers/wallet.py` 新增 `GET /me/consumptions` 查询消费明细。

### 前端
- 修改 `frontend/me.html`：菜单网格中新增"💰 消费明细"入口。
- 新建 `frontend/consumptions.html`：
  - 展示消费记录列表（时间、入口、模型、输入/输出 Token、总 Token、扣费、描述）。
  - 顶部汇总卡片：记录数、累计 Token、累计扣费。
  - 支持加载更多分页。

### 测试
- 新增 `tests/test_billing.py`，覆盖：
  - Token 用量提取（OpenAI 格式）。
  - 多次调用用量累计。
  - 消费记录保存与查询。
  - 计费扣费逻辑。
  - `/me/consumptions` API。
