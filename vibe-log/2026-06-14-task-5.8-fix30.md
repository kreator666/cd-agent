## 任务说明
服务端部署后启动报错：

```
Sync verified users to ip_styles failed
sqlalchemy.exc.OperationalError: (sqlite3.OperationalError) no such column: user_profiles.bio
```

原因是旧版 `memory.db` 中的 `user_profiles` 表缺少 `bio` 列，而 `_sync_verified_users_to_ip_styles` 在初始化时会读取该列。需要提供一个可在服务端独立执行的升级脚本，并在启动时自动兼容旧表结构。

## 完成内容
- 修改 `src/comedy_agent/memory/medium_term.py`：
  - 在 `SQLMemoryStore` 初始化迁移逻辑中新增 `user_profiles.bio` 列检查。
  - 旧表缺少该列时自动执行 `ALTER TABLE user_profiles ADD COLUMN bio TEXT`。
- 新增 `scripts/migrate_add_user_profiles_bio.py` 独立升级脚本：
  - 默认读取项目配置 `settings.memory_db_path`。
  - 支持通过环境变量 `MEMORY_DB_URL` 指定非默认数据库路径。
  - 幂等执行：若列已存在则跳过。
- 验证：
  - 模拟旧 schema 创建数据库，脚本成功添加 `bio` 列。
  - 重复执行脚本确认幂等性。
  - 启动 `SQLMemoryStore` 时自动迁移通过。
  - `tests/test_memory_schema.py` 全部通过（10/10）。
