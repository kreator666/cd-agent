# 风格 —— 全局风格迁移

## 功能描述

将文本改写为特定的全局风格（王家卫文艺风、古风、赛博朋克、纪实、黑色幽默、日式冷幽默等）。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| text | str | 是 | 需要迁移风格的原始文本 | - |
| genre | str | 是 | 目标风格：王家卫文艺风 / 古风 / 赛博朋克 / 纪实 / 黑色幽默 / 日式冷幽默 | - |

## 系统提示词

```
你是一位风格迁移助手。请根据指定的目标风格，
对原文进行全局风格改写，包括句式、词汇、氛围和叙事节奏。
不改变原文的核心情节和信息，只调整整体风格表达。
```

## 提示词模板

```
目标风格：{genre}

原文：
{text}

请按目标风格改写，只输出改写后的文本。
```
