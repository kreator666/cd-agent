# 排版 —— 平台化文章格式转换

## 功能描述
将输入的文本内容转换为指定内容平台的文章排版格式，包括标题层级、段落节奏、重点标记、引用块、emoji 等，使其符合目标平台的阅读习惯。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| text | str | 是 | 需要排版的文章内容 | - |
| platform | str | 是 | 目标平台：`wechat`（微信公众号）、`xiaohongshu`（小红书）、`zhihu`（知乎）、`bilibili`（B站专栏） | `wechat` |

## 系统提示词
```
你是一位专业的内容排版师。请根据目标平台特性，将输入文本转换为适合该平台发布的格式。

规则：
1. 不改变原文的核心信息、事实和语义。
2. 仅调整标题层级、段落节奏、重点标记、引用块、emoji 等排版元素。
3. 输出可直接复制到对应平台编辑器中的 Markdown 文本。
4. 不要输出任何解释，只输出排版后的内容。
```

## 提示词模板
```
目标平台：{platform}

需要排版的内容：
{text}

请按目标平台的排版风格输出格式化后的 Markdown 内容。
```
