## 任务说明
用户反馈 pro-b.html 的两个交互问题：
1. 点击“修改”时，应该让人工直接在 reviewer 回复面板里编辑段落，确认后再反馈到右侧结果区域，而不是让模型重新生成。
2. 右侧工作区最后的结果显示了 2 个卡片（段落草稿卡片 + 最终剧本卡片重复）。

## 完成内容

### 1. 人工编辑段落
- 前端 `pro-b.html`：
  - 将 human_review 的段落文本渲染为可编辑区域（`.review-section`）。
  - 点击“修改”后进入编辑模式，显示“确认修改”和“取消”按钮。
  - 确认后，段落文本立即同步更新右侧结果区对应卡片。
  - 以 `[manual]\n编辑后文本` 的形式静默提交给后端。
- 后端 `process_feedback_node`：
  - 识别 `[manual]` 前缀，直接把编辑后的文本替换到 `state.sections[current_section]`。
  - 不调用 Writer Agent 重写，直接进入下一段或收尾。

### 2. 最终剧本去重
- 前端在收到 `type === 'final_script'` 时，先调用 `clearSectionArtifacts()` 清除中间段落草稿卡片。
- 只保留最终剧本卡片，避免右侧出现段落草稿 + 最终剧本两个重复内容卡片。

### 3. 重构
- 将 `sendPrompt` 的 API 调用与响应处理提取为 `runAgentTurn(text, silent)`，支持静默反馈（不显示用户消息）。
- 新增 `bindGuideActions`、`renderGuideContentHtml`、`splitHumanReviewContent`、`getSectionArtifactId`、`finishSectionEdit` 等辅助函数。

### 4. 测试
