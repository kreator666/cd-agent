## 任务说明
为 Comedy Agent 接入调用链追踪、延迟监控与 Token 消耗统计，支持 LangSmith 自动配置，同时保留自建指标兜底。

## 完成内容
- 新增 `core/observability.py`：
  - `TraceSpan` —— 单个调用段，支持嵌套子 Span、自动截断输入输出
  - `Tracer` —— 调用链追踪器，上下文管理器风格，自动维护调用树
  - `MetricsCollector` —— 轻量级指标收集器，支持按标签聚合与汇总统计
  - `setup_langsmith()` —— 若配置了 `LANGSMITH_API_KEY` 则自动启用 LangSmith 追踪
  - `reset_observability()` —— 用于测试清理全局状态
- 集成到 `agent/orchestrator.py`：
  - `run()` / `arun()` 注入 `agent.run` / `agent.arun` 追踪 Span
  - 记录执行延迟与 Token 消耗指标
- 集成到 `rag/retriever.py`：
  - `retrieve()` 注入 `retriever.retrieve` 追踪 Span
  - 记录缓存命中、向量/BM25 召回数量、最终返回数量与延迟
- 集成到 `models/factory.py`：
  - `get_model()` 记录模型调用次数（按模型名与任务类型打标签）
  - `get_model_with_fallback()` 记录 Fallback 链激活指标
- API Server 增强：
  - lifespan 启动时自动调用 `setup_langsmith()`
  - `/chat` 与 `/feedback/ingest` 端点注入追踪与延迟指标
  - 新增 `GET /metrics` 端点，返回最近调用链与聚合指标（内部调试）
- 测试：
  - 新增 `tests/test_observability.py`，覆盖 TraceSpan、Tracer、MetricsCollector、setup_langsmith、全局单例与 reset，共 16 个用例全部通过
  - 全量测试 313 passed, 7 skipped，无回归
