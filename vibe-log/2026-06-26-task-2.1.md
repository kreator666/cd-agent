## 任务说明
额外创建一个前端页面「专业版 B」，保持与现有「专业版」页面相同的左侧工具栏图标与整体功能，但所有对话请求改走后端新接口 `/pro/chat-v4`，该接口直接接入 v4 LangGraph StateGraph（`state.graph`）。

## 完成内容
- 新增 `frontend/pro-b.html`：
  - 基于 `frontend/pro.html` 复制，保留左侧工具栏图标与布局。
  - 标题改为「专业版B｜剧本工坊」，导航栏 active 指向自身。
  - 将聊天 POST 端点从 `/pro/chat` 改为 `/pro/chat-v4`。
  - 将历史恢复 GET 端点从 `/pro/chat/{session_id}` 改为 `/pro/chat-v4/{session_id}`。
  - `localStorage` 对话历史 key 改为 `pro_b_conversations`，避免与原版互相覆盖。
- 新增 `src/comedy_agent/api/routers/pro_v4.py`：
  - `POST /pro/chat-v4`：接收 `ProChatV4Request`，调用 `state.graph.ainvoke`。
    - 若 checkpoint 当前 phase 为 `human_review` / `routing_feedback`，使用 `Command(resume=message)` 恢复中断。
    - 否则以新 `ComedyState` 启动创作流程。
  - `GET /pro/chat-v4/{session_id}`：读取 checkpoint 状态，用于前端恢复历史对话。
  - 将 v4 Graph 输出封装为兼容 `pro.html` 前端的 `ProChatV4Response`：
    - `complete` → `type=final_script` + script artifact
    - `__interrupt__` → `type=guide` + `workflow_state=human_review` + section artifact + 通过/修改/重写快捷操作
    - 其它完成态 → `type=guide` / `skill_output`
- 修改 `src/comedy_agent/api/server.py`：注册 `pro_v4_router`。
- 新增 `tests/test_pro_v4.py`：覆盖完成态、interrupt、feedback 恢复、加载会话 4 个场景。
