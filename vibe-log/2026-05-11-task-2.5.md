## 完成内容
- **新增 `core/prompt_manager.py`** — Prompt 管理器核心实现
  - 单例模式：`PromptManager()` 全局统一管理所有 Prompt 模板
  - **注册**：`register(name, template, version)` 内存注册
  - **加载**：`load_from_file()` 单文件加载 / `load_from_directory()` 批量目录加载
    - 支持两种文件命名约定：
      - 扁平结构：`{name}_v2.txt` → `name` 的 `v2` 版本
      - 嵌套结构：`{name}/v2.txt` → `name` 的 `v2` 版本
  - **渲染**：`render(name, variables, version)` 变量注入
    - 检测到 Jinja2 语法（`{{` / `{%`）时优先使用 Jinja2 渲染
    - 无 Jinja2 标记时使用 `str.format()`
    - Jinja2 未安装或渲染失败时自动降级
    - 变量缺失时保留原始占位符并记录 warning
  - **版本查询**：`list_versions(name)` / `list_prompts()` / `get(name, version)`
  - **A/B 测试**：
    - `get_ab_version(name, config, seed)` — 按流量比例随机选择版本
    - `render_ab(name, variables, config, seed)` — 返回 (版本号, 渲染文本)
    - `config` 为版本 → 权重的字典，如 `{"default": 0.8, "v2": 0.2}`
- **配置更新**：`core/config.py` 新增 `prompts_dir` 路径配置
- **示例 Prompt 模板**：`data/prompts/`
  - `standup_system.txt` — 脱口秀 System Prompt
  - `standup_user.txt` — 脱口秀用户 Prompt（Jinja2 语法）
  - `standup_user_v2.txt` — v2 版本（更口语化风格）
- **StandupSkill 重构作为示例**
  - `_get_system_prompt()` / `_build_user_prompt()` 优先从 `PromptManager` 加载外部模板
  - 外部模板不存在时自动 fallback 到内置 Prompt，保持向后兼容
- **CLI / HTTP Server**：启动时自动调用 `PromptManager().load_from_directory()`
- **测试覆盖**（`tests/test_prompt_manager.py` 共 14 项）
  - 注册/查询/多版本/list
  - 文件加载（扁平/嵌套/版本化文件名）
  - 渲染（str.format / Jinja2 / 缺失变量降级）
  - A/B 测试（均分/加权/缺失 Prompt 异常）
