## 任务说明
依据 `docs/design/v4/development_plan_master.md` 的 Phase 1 目标，实现确定性四阶段状态机，用代码条件边控制状态流转，并集成 `interrupt()` 实现 Human-in-the-Loop。本阶段解决之前“状态流转混乱”的核心问题，为后续多 Agent 协作打下基础。

Phase 1 验收标准：
1. 完整 Pydantic StateSchema，支持运行时校验；
2. 所有阶段切换由 `graph/edges.py` 中的代码函数决定，0 处模型判断流程；
3. 具备 analyze → plan → write → review → human → process_feedback → finalize 的完整创作链路；
4. 每段写作后通过 `interrupt()` 暂停，等待人类反馈；
5. `/chat` 端点支持通过 `Command(resume=...)` 恢复中断；
6.  milestone M1：输入一个脱口秀主题，系统完成“分析→计划→写作→人类审阅→修改/通过→完成”的完整流程。

## 完成内容
- 扩展 `src/comedy_agent/state/schema.py`：定义完整 `ComedyState`，新增 `intent`、`analysis`、`plan`、`current_section`、`sections`、`review`、`feedback` 等字段，支撑完整创作状态。
- 新增 `src/comedy_agent/graph/edges.py`：所有条件边均为纯 Python 函数，根据 `phase`/`intent` 等状态字段决定下一节点。
- 更新 `src/comedy_agent/graph/builder.py`：构建完整创作状态机 `entry → analyze → plan → write → review → human → process_feedback → finalize`，同时保留 `chat` 直连路径。
- 新增各阶段节点：
  - `entry_node`：规则化意图分类（writing / chat / search / control / feedback）。
  - `analyze_node`：调用 LLM 输出话题/态度/偏见/情绪四维度 JSON，并带兜底解析。
  - `plan_node`：生成 `todo` + `outline` + `tone`，初始化 `current_section` 与 `sections`。
  - `write_node`：按 outline 逐段撰写，注入已完成段落与人类反馈上下文。
  - `review_node`：审核当前段落，输出 decision/comments/score。
  - `human_node`：使用 `interrupt()` 暂停，等待人类反馈。
  - `process_feedback_node`：解析“通过/修改/重写/重新规划”等反馈，更新 `current_section` 与 `phase`。
  - `finalize_node`：合并所有段落为最终输出。
- 更新 `src/comedy_agent/api/server.py`：
  - `/chat` 支持 `feedback` 字段恢复 interrupt；
  - 返回 `status=waiting_feedback` 与当前段落文本；
  - 修复 `ModelFactory` 重复导入。
- 新增/补充测试：
  - `tests/test_state_machine.py`：条件边分支与基础状态流转。
  - `tests/test_interrupt.py`：中断暂停、`Command(resume=...)` 恢复、通过/修改反馈路径。
  - `tests/test_phase1_full_flow.py`：
    - 3 段 outline 逐段“通过”后最终输出完整文本；
    - “修改意见”触发当前段重写并再次暂停等待反馈。
