## 任务说明
在 `TheoryStore` 之上封装统一检索接口，支持向量检索、关键词检索、元数据过滤与 RRF 融合，供 Planner 和 Writer 调用。

## 完成内容
- 新增 `src/comedy_agent/core/knowledge_system.py`
  - `KnowledgeSystem` 类：封装 `TheoryStore` + 关键词索引 + RRF 融合。
  - `retrieve_knowledge()` 便捷函数。
  - 向量检索失败时自动降级到关键词检索。
  - 支持按 `category`（concept/technique/pattern/rule）过滤。
  - 关键词索引从 `data/knowledge/knowledge_items.jsonl` 加载，使用 `lru_cache` 避免重复读取。
- 检索流程：
  1. 向量检索 `TheoryStore.search()`（默认召回 Top-10）。
  2. 关键词检索基于 token 重叠（默认召回 Top-10）。
  3. RRF 融合两路结果，按最终分数排序返回 Top-K。
- 新增 `tests/test_knowledge_system.py`
  - 分词工具测试。
  - 关键词检索与类别过滤测试。
  - RRF 融合测试（向量 + 关键词共同命中、仅关键词命中）。
  - `KnowledgeSystem.retrieve` 单元测试（mock TheoryStore）。
  - 真实 `TheoryStore` + `hf-local` Embedding 集成测试。
- 手动验证：
  ```python
  from comedy_agent.core.knowledge_system import retrieve_knowledge
  retrieve_knowledge('三番四抖', top_k=3)
  # 返回：['三番四抖', '小品三幕结构', '喜剧节奏与预期管理']
  ```
