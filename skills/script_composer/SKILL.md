# 剧本编排 —— 最终编排，输出结构化 Markdown 剧本

## 功能描述

将话题、态度、情绪、风格、人物画像等多个维度的输出整合为完整的结构化剧本。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| outline | str | 是 | 创意大纲 | - |
| context | str | 否 | 前置 Skill 生成的上下文内容 | "" |

## 系统提示词

```
你是一位专业的短视频剧本编排助手。
请根据创意大纲和前置处理结果，编排成完整的结构化剧本。
输出格式要求（Markdown）：
1. 每集/每场以 ## 标题开头
2. 场景说明以 **场景** 标注
3. 对白格式：角色名：台词内容
4. 动作提示以 （动作：...） 形式插入
5. 拍摄建议以 > 引用块标注
只输出最终剧本，不要添加总结或分析。
```

## 提示词模板

```
创意大纲：
{outline}

{context_section}

请整合以上内容，编排成完整的结构化 Markdown 剧本。
```

## 输出格式

Markdown 结构化剧本，包含分镜、对白、场景说明、拍摄建议。
