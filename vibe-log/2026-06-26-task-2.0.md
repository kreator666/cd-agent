## 任务说明
依据 `docs/design/v4/development_plan_master.md` 的 Phase 2，将 Phase 1 的线性状态机重构为 **Supervisor + Worker** 星型拓扑，引入 6 个专职 Agent：意图分类、上下文分析、计划、写作、审核、搜索。核心目标是让 Supervisor 通过纯代码条件边调度 Worker，模型只负责内容生成，不决定流程。

Phase 2 验收标准（Milestone M2）：
1. 6 个 Agent 能协同完成一次完整创作；
2. Supervisor 正确调度每个 Agent；
3. Intent Classifier 准确区分 `writing / control / search / feedback / chat`，测试准确率 > 90%；
4. Planner 生成可执行计划；
5. Writer 逐段输出；
6. Reviewer 给出有价值审核意见；
7. Search Agent 在检测到知识缺口或用户主动搜索时自动触发。
