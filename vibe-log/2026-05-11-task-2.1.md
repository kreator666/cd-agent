## 完成内容
- **CrosstalkSkill** (`skills/crosstalk.py`): 相声剧本生成器
  - 支持传统相声与新相声风格
  - 参数：主题、风格、篇幅、逗哏/捧哏角色设定
  - 输出格式：【逗哏】/【捧哏】标注对白，（包袱）/（抖）标注笑点位置
- **SketchSkill** (`skills/sketch.py`): 小品剧本生成器
  - 参数：主题、角色数（2-5人）、场景设定、时长
  - 结构：角色介绍 → 场景描述 → 正戏 → 高潮 → 结尾
- **SitcomSkill** (`skills/sitcom.py`): 情景喜剧单集生成器
  - 支持 A/B 故事线并行结构
  - 参数：情景设定、本集主题、常驻角色、场景数
  - 特色：结尾 callback 呼应早期细节
- **JokeAnalyzerSkill** (`skills/joke_analyzer.py`): 笑点分析工具
  - 分析维度：结构分析 / 节奏分析 / 预期违背分析 / 语言技巧分析 / 综合分析
  - 输出：结构拆解、节奏评估、优点总结、改进建议
- **ScriptEvaluatorSkill** (`skills/script_evaluator.py`): 剧本评估工具
  - 6 项评分维度：笑点密度、角色塑造、结构完整性、口语化程度、表演可行性、情感共鸣
  - 输出：逐项评分（满分10分）、综合评分、问题诊断、改进建议、参考案例
- 更新 `skills/__init__.py` 统一导出全部 Skill
- 更新 CLI (`api/cli.py`) 与 HTTP Server (`api/server.py`)，启动时自动注册全部 6 个 Skill
