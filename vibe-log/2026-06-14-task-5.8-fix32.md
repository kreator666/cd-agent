## 任务说明
执行 `scripts/migrate_sync_schema.py` 时报错：

```
[error] Failed to add column user_profiles.is_verified: (sqlite3.OperationalError) Cannot add a NOT NULL column with default value NULL
[SQL: ALTER TABLE "user_profiles" ADD COLUMN is_verified BOOLEAN NOT NULL]
```

原因是为已有表添加 NOT NULL 列时，SQLite 要求必须指定默认值；原脚本虽然检查了默认值，但仅对没有 Python `default` 的列才附加数据库 DEFAULT，导致 `is_verified`（有 `default=False` 但无 `server_default`）生成的 SQL 缺少 DEFAULT。

## 完成内容
- 修复 `scripts/migrate_sync_schema.py`：
  - `_column_definition` 直接返回 `CreateColumn` 生成的列定义。
  - 对所有 `NOT NULL` 且没有数据库级 `server_default` 的列，统一附加 SQLite 兼容的 DEFAULT 值。
- 同步修复 `src/comedy_agent/memory/medium_term.py` 中的 `_sync_schema()` 方法，保持逻辑一致。
- 验证：
