# 铺垫-反转

一个反转机会，用满用透：观众以为 A，其实是 B。

## 骨架

建立预期 → 细节加固 → 一句话翻转

## 分段标签

```
【铺垫】
一秒入戏的日常场景，建立"理所当然"的预期（前 5 秒必须有抓人细节）

【加固】
再往 A 方向加 1-2 个具体细节，让观众彻底相信

【爆梗】
一句话翻转到 B 方向，主爆梗炸开

【收尾】
回扣铺垫里的一个小细节，mini callback 再炸一次
```

## 写法要点

- 铺垫越"真"越好，反转才越意外——但 B 必须合理，不能无厘头。
- 反转句要短，一句话完成翻转，不要解释笑点。
- 30 秒内只反转一次，翻转前不再抖小梗。

## 示例

【铺垫】我妈总说外卖脏，天天给我送饭。
【加固】送了三个月，风雨无阻，感动全公司。
【爆梗】直到我发现，她顺路给隔壁小王也送，还送俩菜。
【收尾】现在她俩亲妈干儿子相称，我才是外卖。
