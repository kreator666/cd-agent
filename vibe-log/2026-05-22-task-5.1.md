## 任务说明
实现 Skill 插件的自安装、卸载和热重载能力，包括：
1. Orchestrator 扩展（注册/卸载/热重载）
2. Loader 热重载支持（扫描/加载单个 Skill）
3. API 端点开发（安装/卸载/重载/列表）
4. 安全校验（名称正则、AST 语法、内置白名单、路径限制）
5. 测试覆盖

## 完成内容

### Orchestrator 扩展
- **修改 `agent/orchestrator.py`**：
  - 新增 `unregister_skill(name)` 方法：从 `self.tools` 移除指定 Skill，重置 Agent 缓存
  - 内置 Skill 白名单保护：6 个内置 Skill（standup_generator 等）不可卸载
  - 新增 `reload_plugins(skills_dir)` 方法：扫描磁盘，注册新增 Skill、移除已删除 Skill，返回统计
  - `list_skills()` 返回类型增强：`list[str]` → `list[dict]`，含 `name`, `description`, `task_type`, `source`

### Loader 热重载
- **修改 `skills/loader.py`**：
  - 新增 `scan_skills_dir(skills_dir)`：扫描 `skills/` 目录，返回合法 Skill 目录列表
  - 新增 `load_single_skill(skill_dir)`：加载单个 Skill（复用现有解析逻辑）
  - `load_plugin_skills()` 改为复用 `load_single_skill()`，避免重复代码

### API 端点开发
- **修改 `api/server.py`**：
  - `GET /skills`：已适配新的 `list_skills()` 返回格式（`SkillListResponse.skills` 为 dict 列表）
  - `POST /skills/install`：通过 multipart form 接收 name + SKILL.md + prompt.txt + skill.py，写入磁盘并注册
  - `DELETE /skills/{name}`：卸载指定 Skill（内置 Skill 返回 403）
  - `POST /skills/reload`：触发热重载，返回 added/removed/unchanged 统计

### 安全校验
- **修改 `skills/loader.py`**：
  - `validate_skill_name(name)`：正则 `^[a-zA-Z0-9_-]+$`，长度 ≤ 64
  - `validate_skill_py(code)`：`ast.parse()` 确保语法合法
  - `is_builtin_skill(name)`：判断是否为内置 Skill
  - 安装时路径限制在 `settings.skills_dir`，禁止目录遍历
