## 完成内容
- 新增 `KnowledgeCard` ORM 表与 `KnowledgeCardData` Pydantic 模型
- `SQLMemoryStore` / `UnifiedMemory` 新增知识卡片 CRUD（save/list/get/delete，支持按类型/标签过滤）
- 新增学习模式 Prompt 模板 `data/prompts/learn_system.txt`（支持 explain/analyze/extract 三种子模式）
- 新增 API 端点：
  - `POST /learn/chat` — 学习模式对话，从个人知识库检索 + LLM 分析
  - `POST /learn/cards` — 创建技巧卡片
  - `GET /learn/cards` — 列出技巧卡片（支持 type/tag 过滤）
  - `DELETE /learn/cards/{card_id}` — 删除卡片
  - `POST /debug/retrieve` — 调试知识库检索中间结果
- 前端 sidebar 新增：
  - "📚 学习模式"按钮 → Modal 弹窗（选择文档、输入问题、选择分析模式、查看 AI 回答）
  - "技巧库"折叠面板（创建卡片、列表展示、删除卡片）
