## 任务说明

在上一个任务（4.3）实现的 `script_coach` Skill 基础上，把「段子打磨」能力集成到「笑果评测」的结果展示页：

- 用户生成段子后，在每条结果卡片上出现「打磨」按钮；
- 点击打开配置弹窗，可设置迭代轮数、提前终止阈值、参考文稿数；
- 后端调用 `script_coach` Skill 对当前结果进行顶流参照评分与循环优化；
- 前端展示最终成品、每轮评分记录、差距诊断与可改进点；
- 最终作品继续保存到用户作品库，不混入顶流文稿库。

## 完成内容

- 后端 `src/comedy_agent/api/routers/eval.py`：
  - 新增 `CoachRequest` / `CoachResponse` Pydantic 模型；
  - 新增 `POST /eval/results/{result_id}/coach` 接口；
  - 鉴权仅允许作者打磨自己的结果；
  - 校验结果状态必须为 `done` 且内容非空；
  - 从 `EvalSession` 读取 topic/attitude/emotion/duration，
    将 attitude/emotion 映射为 `script_coach` 的 `style`；
  - 通过 `load_single_skill` 加载 `script_coach`，并注入 `state.orch.memory`；
  - 返回 JSON 结构给前端。
- 前端 `frontend/eval.html`：
  - 已生成完成的结果卡片 actions 区新增「打磨」按钮；
  - 新增打磨配置弹窗（coach-modal），支持设置：
    - 最大迭代轮数 1-5
    - 提前终止阈值 1-10
    - 参考顶流文稿数 1-20
  - 弹窗内展示：
    - 最终成品（可复制）
    - 结束原因
    - 每轮综合分、各维度评分、与顶流差距、可改进点、改写方向
  - 新增 `openCoachModal` / `closeCoachModal` / `submitCoach` / `renderCoachResult` / `copyCoachResult` 函数。
- 测试 `tests/test_eval_api.py`：
  - 新增 `TestEvalCoach` 测试类，覆盖打磨成功流程与结果不存在流程，共 2 个用例。
