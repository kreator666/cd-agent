## 任务说明
用户反馈：专业版 B 右侧工作区（artifacts panel）中，每次生成新的段落内容都会重复输出到同一个卡片里，应该是新增卡片展示。

## 完成内容
- 问题定位：`/pro/chat-v4` 在 `human_review` 返回的段落 artifact 使用了固定 ID `{session_id}-section`，导致前端 `applyArtifactOp` 把多段内容更新到同一张卡片。
- 修复方案：
  - 从 interrupt payload 中读取 `section_index`。
  - artifact ID 改为 `{session_id}-section-{section_index}`，保证每段唯一。
  - artifact 标题从“当前段落”改为“第 N 段”，便于用户区分。
- 前端逻辑无需改动，因为 `createArtifactCard` 在 ID 唯一时会自动新建卡片。
