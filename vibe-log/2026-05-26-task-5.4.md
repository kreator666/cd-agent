## 任务说明
之前发现 RAG 知识库基础设施（VectorStore、ComedyRetriever、ContextInjector、FeedbackLoop）虽已完整实现，但 Orchestrator 并未接入，导致内置 Skill 创作时无法引用知识库内容。本任务完成接入。

## 完成内容

### 修改 `agent/orchestrator.py`
- `__init__` 新增 `retriever` 参数（可选）
- 将 `_build_memory_system_prompt()` 重构为 `_build_system_prompt(user_input, user_id)`
- 新的 System Prompt 构建逻辑：
  1. 基础 System Prompt
  2. 用户记忆（若配置了 memory + user_id）
  3. 知识库检索结果（若配置了 retriever）— 调用 `retriever.retrieve(user_input, top_k=5)`，将结果格式化为引用列表注入
- 检索失败时不抛异常，仅记录 debug 日志，避免阻塞创作流程
- `run()` 和 `arun()` 统一使用 `_build_system_prompt()` 构建完整的 System Prompt

### 修改 `api/server.py`
- lifespan 中新增知识库初始化逻辑：
  - 创建 `VectorStore(collection_name="comedy_knowledge", persist_path=settings.vector_db_path)`
  - 创建 `ComedyRetriever(vector_store=vector_store)`
  - 将 retriever 传入 `AgentOrchestrator(memory=state.memory, retriever=retriever)`
- 知识库初始化失败时不阻塞启动，仅记录 warning，确保服务可用性

## 数据流

```
用户输入 ──→ AgentOrchestrator.run()
              ├── _build_system_prompt(user_input, user_id)
              │   ├── 基础 System Prompt
              │   ├── 用户记忆（UnifiedMemory.build_context_text）
              │   └── 知识库检索（ComedyRetriever.retrieve，top_k=5）
              │       ├── 向量检索召回
              │       ├── BM25 关键词检索召回
              │       ├── 合并去重 + Cross-Encoder 重排序
              │       └── 格式化为引用列表注入 Prompt
              └── Agent.invoke(messages) → Skill 执行
```
