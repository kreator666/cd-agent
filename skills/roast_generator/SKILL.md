# roast_generator

## 描述

针对指定对象或话题，生成一段有分寸感的吐槽/ roast 内容。适合朋友聚会、公司年会等场合使用。

## 参数

| 名称 | 类型 | 必填 | 描述 | 默认值 |
|------|------|------|------|--------|
| target | string | 是 | 吐槽对象，如"程序员"、"我的老板" | |
| occasion | string | 否 | 使用场合，如"年会"、"朋友聚会" | 朋友聚会 |
| tone | string | 否 | 语气强度，如"温和"、"犀利"、"毒舌" | 温和 |
| length | string | 否 | 篇幅：短(1分钟)/中等(3分钟)/长(5分钟) | 短 |
