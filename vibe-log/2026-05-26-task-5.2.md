  - 包含：Skill 列表容器、底部操作栏（安装 Skill / 热重载按钮）
  - 新增「安装 Skill」Modal（`install-skill-modal`），包含：
    - Skill 名称输入框
    - SKILL.md 内容 textarea
    - prompt.txt 内容 textarea
    - skill.py 代码内容 textarea（可选）

### CSS 样式
- `.skill-section` / `.skill-list` / `.skill-item` — 与「我的作品」风格一致
- `.skill-source.builtin` — 绿色标签（#16c79a）
- `.skill-source.plugin` — 橙色标签（#f5a623）
- `.skill-actions-bar` — 底部双按钮布局
- `.modal-box textarea` — 统一 textarea 样式

### JavaScript 逻辑
- `loadSkills()` — 页面初始化时调用 `GET /skills`，缓存到 `window._skills`
- `renderSkillList()` — 渲染列表，内置 Skill 显示绿色 badge，插件 Skill 显示橙色 badge + 卸载按钮
- `openInstallSkillModal()` / `closeInstallSkillModal()` — 控制安装 Modal
- `confirmInstallSkill()` — 调用 `POST /skills/install`，成功后刷新列表
- `uninstallSkill(name)` — 确认后调用 `DELETE /skills/{name}`，成功后刷新列表
- `reloadSkills()` — 调用 `POST /skills/reload`，弹出 added/removed/unchanged 统计
