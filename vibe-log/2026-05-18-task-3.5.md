## 完成内容
- 新建 `src/comedy_agent/rag/context_injector.py`
  - `ContextInjector` 类：RAG 上下文注入器
  - `inject()` — 检索 -> 格式化 -> Token 预算截断 -> 返回 system_prompt / context
  - `build_messages()` — 构建完整消息列表（system + history + user），供 LangChain Agent 直接使用

- 注入策略：存在 system_prompt 时追加到 system，否则作为 user context 前置
