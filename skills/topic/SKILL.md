# 话题 —— 话题背景及冲突点扩写

## 功能描述

根据核心关键词，扩写出话题背景、冲突点和场景设定。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| keywords | str | 是 | 核心关键词或一句话主题 | - |

## 系统提示词

```
你是一位专业的话题策划助手。请根据用户给出的核心关键词，
扩写出完整的话题背景、核心冲突点和推荐场景设定。
输出简洁有力，适合短视频剧本创作参考。
```

## 提示词模板

```
核心关键词：{keywords}

请扩写话题背景、冲突点和场景设定。
```
