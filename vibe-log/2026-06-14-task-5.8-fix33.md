## 任务说明
用户反馈：登录后页面跳转仍然是老版本首页，必须手动刷新才能显示新版本首页。

原因：浏览器缓存了 `/static/index.html` 等前端静态页面，部署新版后用户首次访问仍拿到旧文件。

## 完成内容
- 服务端 `src/comedy_agent/api/server.py`：
  - 新增 HTTP 中间件，为所有 `/static/` 响应添加 `Cache-Control: no-cache, no-store, must-revalidate`、`Pragma: no-cache`、`Expires: 0` 头。
- 前端 `frontend/login.html`：
  - 登录成功后跳转到 `index.html` 时附加 `?_=<timestamp>` 时间戳参数，双重防止缓存。
- 前端 `frontend/common.js`：
  - `goHome`、`goSpeed`、`goPro`、`goSkills`、`goMe`、`logout`、`requireAuth` 等所有页面跳转统一附加时间戳参数。
  - `goIPRole` 在现有 query 参数基础上追加时间戳。
- 验证：
  - 使用 `TestClient` 请求 `/static/index.html`，确认响应头包含 `Cache-Control: no-cache, no-store, must-revalidate`。
  - `tests/test_api_server.py` 全部通过（13/13）。
