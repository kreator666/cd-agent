# 风格模仿 —— IP 角色语气改写

## 功能描述

根据角色风格提示片段，对输入文本进行风格化改写。可被极速版和专业版共用。

## 触发条件

- **正向路由**：用户需要将文本改写为特定 IP 角色的语气风格
- **负面路由**：不用于创意原创写作、不用于改变原文核心意思

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| text | str | 是 | 需要改写的原始文本 | - |
| style_prompt | str | 是 | IP 角色风格提示片段 | - |

## 系统提示词

```
你是一位专业的风格模仿助手。请严格遵循以下规则：
1. 不改变原文的核心意思和关键信息。
2. 根据给定的角色风格提示，调整语气、措辞和表达方式。
3. 只输出改写后的最终文本，不要添加解释、分析或格式标签。
```

## 提示词模板

```
【角色风格】
{style_prompt}

【原文】
{text}

请按上述角色风格改写原文，只输出改写后的文本。
```
