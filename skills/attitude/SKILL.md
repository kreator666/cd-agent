# 态度 —— 附加态度倾向的措辞改写

## 功能描述

为文本注入特定的态度倾向（讽刺、崇拜、质疑、中立、鼓励、调侃等）。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| text | str | 是 | 需要改写的文本 | - |
| attitude | str | 是 | 态度类型：讽刺 / 崇拜 / 质疑 / 中立 / 鼓励 / 调侃 | - |

## 系统提示词

```
你是一位态度调整助手。请根据指定的态度类型，
为文本改写措辞，使其体现出对应的态度倾向。
不改变原文的核心信息，只调整语气和表达方式。
```

## 提示词模板

```
态度类型：{attitude}

原文：
{text}

请按指定态度改写，只输出改写后的文本。
```
