## 任务说明
修复专业版 B（`frontend/pro-b.html` / `/pro/chat-v4`）的交互逻辑，使其符合预期：用户通过 `@` 选择填满 4 个维度槽位（话题 / 态度 / 偏见 / 情绪）→ 检查 Agent 确认槽位完整 → Planner 生成计划 → Writer 逐段写作。

## 完成内容
- 扩展 `ComedyState`：
  - 新增 `slots: dict[str, str]` 用于保存 4 维度槽位
  - 新增 `response_type: Literal["guide", "script", "error"]` 用于区分最终输出类型
  - intent 枚举新增 `fill_slot`
  - phase 新增 `filling_slots` / `slot_checking`
- 新增 `SlotFillingAgent`（`agents/slot_filler.py`）：
  - 解析 `@话题 内容`、`@态度 内容`、`@偏见 内容`、`@情绪 内容`
  - 同时支持显式声明：`话题：内容`、`我的话题是内容` 等
  - 更新 `state.slots` 后进入 `slot_checking`
- 新增 `SlotCheckingAgent`（`agents/slot_checker.py`）：
  - 若槽位未填满：返回 `response_type=guide` + 引导语，提示用户继续 @ 填槽
  - 若槽位已满：将槽位映射为 `analysis`，进入 `planning`
- 新增节点适配层 `slot_filler_node` / `slot_checker_node`
- 更新 `SupervisorAgent` 与 `graph/supervisor_graph.py`：
  - `writing` / `fill_slot` 意图 → `filling_slots` → `slot_filler` → `slot_checker`
  - 检查通过 → `planner` → `writer` → `reviewer` → `human`
- 更新 `IntentClassifierAgent`：识别 `@` 填槽意图，默认创作流程先进入填槽阶段
- 更新 `chat_node` / `finalize_node` / `search` 设置 `response_type`，便于前端区分 guide / script
- 更新 `pro_v4.py` 响应封装：根据 `response_type` 返回 `guide` 或 `final_script`，并把 `slots` 返回给前端
- 更新相关测试，新增 @ 填槽与 guide 响应覆盖
