# 短视频爆笑段子输出模板

> 适用：单人口播短视频，30 秒以内。核心是"快速铺垫 → 密集爆梗 → 干净收尾"。

## 输出规格

### 硬约束

1. **时长 ≤ 30 秒**：中文口播正文约 100~150 字，绝不超过 180 字。
2. **爆梗密度**：1 个主爆梗，或 2~3 个连续小梗；不要平铺直叙。
3. **剧情完整但简短**：一条明确的剧情线——铺垫 →（升级）→ 爆点/反转，有头有尾。
4. **结构标签**：用 `【】` 整行标签分段，标签后接该段正文。

### 结构规范（固定 4 段，优先使用）

```
【铺垫】
快速建立场景与人物，让观众进入预期
（前 5 秒必须抓人，1-2 句）

【升级】
推进或加码，把观众往 A 方向引，蓄力爆点
（1-2 句）

【爆梗】
揭示其实是 B 方向：主爆梗在这里炸，
或 2~3 个连续小梗密集引爆

【收尾】
一句话收口，可回扣爆梗做 mini call back，干净利落
```

如内容确实极简，可只用 3 段：`【铺垫】` / `【爆梗】` / `【收尾】`，但优先 4 段。

## 创作步骤

### Step 1：一句话核心反差

用一句话说清"观众以为 A，其实是 B"。短视频只有一个反转机会，必须锋利。

### Step 2：铺垫要"真"、要"快"

- 铺垫必须是观众一秒就能相信的日常场景。
- 前 5 秒必须出现抓人的细节或冲突，禁止慢热。

### Step 3：爆点设计

```
铺垫 = 让观众往 A 方向想（越具体越好）
爆梗 = 揭示其实是 B 方向（越意外越好，但要合理）

主爆梗一个就够，炸得响；
或者用 2~3 个连续小梗形成"连珠炮"节奏。
```

### Step 4：收尾收口

一句话结束，可以回扣爆梗做 mini call back（呼应即可，不需要"遗忘后再炸"的长结构）。

## 手法清单（短视频优先）

| 手法 | 说明 |
|------|------|
| 铺垫-反转 | 核心结构，30 秒内只允许一个主反转 |
| 连珠小梗 | 2~3 个连续小爆点，节奏快过深度 |
| 身份错位 | 我是X但我做了Y，一秒建立 |
| 逻辑滑坡 | 从正常前提一步推到荒谬结论 |
| 反向预期 | 观众以为你会说A，你说了B |
| mini call back | 收尾一句话回扣爆梗 |

## 节奏参考

```
0-5 秒：铺垫抓人（出现一个具体细节或冲突）
5-15 秒：升级蓄力（往 A 方向加码）
15-25 秒：爆梗引爆（B 方向揭示）
25-30 秒：收尾收口（可回扣）
```

## 字数红线

```
正文总字数（不含标签）：100~150 字为宜
绝对上限：180 字
超过 180 字 = 失败，必须删减
```
