# 归谬滑坡

接受一个荒谬前提，一本正经地推到极致，结论炸裂。

## 骨架

接受荒谬前提 → 一本正经推演 → 推到极端 → 结论炸裂

## 分段标签

```
【前提】
接受一个看似合理、其实荒谬的前提（语气越正经越好）

【推演】
用完全严肃的逻辑层层推进（2-3 步，每步都"有道理"）

【结论】
推到极端，结论荒谬到炸裂，主爆梗在此

【收尾】
一句话回扣前提，mini callback 再炸一次
```

## 写法要点

- 推演过程必须逻辑自洽、语气严肃——笑点全在"一本正经地胡说"。
- 每一步只推一小步，让观众来不及喊停就到了悬崖。
- 结论要戳中真实痛点（加班、催婚、内卷），不是单纯荒谬。

## 示例

【前提】老板说我们大家是一个大家庭。
【推演】家人之间不谈钱，所以工资就别计较了。家人要相互扶持，所以下班帮同事干活也是应该的。
【结论】这么推下去，我这不是上班，是回娘家——还不能空手，得自带电脑。
【收尾】不过回娘家能吃饭，在这儿只会吃饼。
