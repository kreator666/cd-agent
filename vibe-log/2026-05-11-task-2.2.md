## 任务说明

## 完成内容
- **新增 `skills/loader.py`** — Skill 插件加载器核心实现
  - `SkillMeta.from_markdown()`: 解析 `SKILL.md` 元数据（名称、描述、参数表格、默认值）
  - `_build_args_schema()`: 根据参数定义动态生成 Pydantic Model（支持 str/int/float/bool 及默认值转换）
  - `_create_declarative_skill()`: 声明式加载模式 —— `SKILL.md` + `prompt.txt` 自动生成 `ComedySkill` 子类
  - `_load_code_skill()`: 代码式加载模式 —— 动态导入 `skill.py` 中的自定义 `ComedySkill` 子类
  - `load_plugin_skills()`: 公共 API，扫描 `skills/` 目录并返回加载成功的 Skill 实例列表
- **更新 CLI / HTTP Server**
  - 启动时自动调用 `load_plugin_skills()` 注册所有外部插件 Skill
- **新增示例插件**: `skills/roast_generator/`
  - `SKILL.md`: 定义吐槽生成器的元数据与参数（target, occasion, tone, length）
  - `prompt.txt`: 专家级 Prompt 模板，支持变量注入
- **新增测试**: `tests/test_skills_loader.py`
  - `TestSkillMeta`: `SKILL.md` 解析测试（含默认值列）
  - `TestBuildArgsSchema`: 动态 Schema 构建测试（必填/选填、类型转换）
  - `TestDeclarativeSkill`: 声明式 Skill 类生成测试
  - `TestLoadPluginSkills`: 目录扫描测试（正常加载、跳过缺失文件、跳过隐藏目录、多 Skill 加载）

## 备注
