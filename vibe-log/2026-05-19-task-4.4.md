## 任务说明
支持保存、查看、编辑用户历史剧本，建立个人作品库。在 4.1/4.2 已完成的 Schema 与存取接口基础上，暴露 RESTful API 和 CLI 命令供上层使用。

## 完成内容
- `api/server.py` 新增 6 个作品管理端点
  - `POST /scripts` — 保存/创建作品（自动分配 script_id）
  - `GET /scripts?user_id=&script_type=` — 列出用户作品，支持类型过滤
  - `GET /scripts/{script_id}` — 查看单个作品详情
  - `PUT /scripts/{script_id}` — 更新作品（支持部分字段更新）
  - `DELETE /scripts/{script_id}` — 删除作品
  - `PATCH /scripts/{script_id}/rate` — 为作品评分
  - 记忆系统未就绪时统一返回 503，作品不存在时返回 404
- `api/cli.py` 新增 `scripts` 子命令组
  - `comedy-agent scripts list --user-id <uid> [--type <type>]` — 表格形式列出作品
  - `comedy-agent scripts get <script_id>` — 查看作品详情与内容
  - `comedy-agent scripts save --user-id <uid> --title <title> --content <content> [--type] [--tags] [--rating]` — 保存新作品
  - `comedy-agent scripts update --user-id <uid> <script_id> [--title] [--content] [--type] [--tags] [--rating]` — 更新作品
  - `comedy-agent scripts delete <script_id>` — 删除作品
  - `comedy-agent scripts rate <script_id> <rating>` — 评分
- 新增 `tests/test_scripts_api.py`：20 个 API 单元测试
  - 覆盖创建、列表、详情、更新、删除、评分全部端点
  - 覆盖成功路径、404/503 错误路径、部分更新、类型过滤
- 新增 `tests/test_scripts_cli.py`：15 个 CLI 单元测试
  - 覆盖全部 scripts 子命令的成功与错误路径
- 修复 API 测试 fixture
  - SQLite 内存数据库在多线程（FastAPI + TestClient）下默认使用 `SingletonThreadPool`，导致表不可见
  - 通过 patch `create_engine` 对 `:memory:` 强制使用 `StaticPool` 解决
