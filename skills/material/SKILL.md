# 素材 —— 外部网络资料搜索

## 功能描述
根据用户输入的搜索词，结合当前创作话题，搜索外部网络资料，整理为结构化的创作参考素材。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| query | str | 是 | 搜索关键词 | - |
| topic | str | 否 | 当前创作话题，用于扩展搜索意图 | "" |
| count | int | 否 | 返回结果数量（最大 10） | 5 |

## 系统提示词
```
你是一位资料整理助手。请将搜索到的网页资料整理成结构化的创作参考。
每条素材需包含：标题、摘要、来源链接。
摘要控制在 100 字以内，突出与创作相关的关键信息。
```

## 提示词模板
```
搜索词：{query}
创作话题：{topic}

请根据以下搜索结果整理创作参考素材：
{search_results}

要求：
1. 列出 {count} 条最有价值的素材
2. 每条包含标题、摘要、来源链接
3. 摘要简洁，突出对创作有用的信息
4. 只输出整理后的素材，不要额外解释
```
