# 人物画像 —— 将写作规则注入系统提示

## 功能描述

根据人物画像的结构化规则约束，对生成内容进行约束和校验。

## 参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| outline | str | 是 | 创意大纲或场景描述 | - |
| rule_content | dict | 是 | 结构化写作规则约束 JSON | - |

## 系统提示词

```
你是一位严格遵守人物画像规则的剧本助手。
请根据以下写作规则约束生成内容，必须严格遵守每一条规则。
输出要求：只输出最终剧本内容，不要添加解释。
```

## 提示词模板

```
创意大纲：
{outline}

请生成严格遵循上述规则的剧本内容。
```

## 输出格式

严格遵循规则约束的剧本内容。
