## 任务说明
根据 multi-prompt.md 建议，将专业版（pro.html）工作流从硬编码步骤推进器重构为状态机驱动的对话交互模式。Get达人 担任中央调度器，统一处理 collect/select/call/aggregate 四种动作。

## 完成内容
- `data/pro_workflow.json`：
  - 升级为状态机 schema：`{initial_state, states, transitions}`
  - 7 个状态定义：awaiting_outline → awaiting_genre → calling_topic → calling_attitude → calling_emotion → calling_rule_persona → aggregating
- `skills/get_daren/SKILL.md` + `skills/get_daren/skill.py`：
  - 创建真正的 Get达人 skill，作为中央调度器
  - `_action_collect`：收集用户槽位（outline 等）
  - `_action_select`：引导用户从 skill_type 中选择专家
  - `_action_call`：调用指定 skill，通过 orchestrator.run 执行
  - `_action_aggregate`：聚合所有历史输出，通过 LLM 提炼最终剧本
  - 返回统一 JSON 结构：`{reply, advance, slots_update, outputs_update}`
- `src/comedy_agent/api/routers/pro_workflow.py`：
  - `_migrate_legacy_workflow`：兼容旧版步骤列表自动迁移为状态机
  - `ProWorkflowEngine` 重构为状态机：维护 `current_state`, `slots`, `outputs`, `log`
  - `process()` 每次调用 Get达人 skill 执行当前状态动作
  - 支持挂起等待用户输入（advance=false）
  - 状态转移和调试日志持久化到 Conversation.metadata
  - admin API `GET/PUT /admin/workflow` 支持新 schema 校验
- `src/comedy_agent/agent/orchestrator.py`：
  - `register_skill` 向 ComedySkill 注入 `orchestrator` 自身，使 Get达人能调度其他 skill
- `src/comedy_agent/skills/base.py`：
  - 新增 `orchestrator` 属性
- `frontend/me.html`：
  - admin 工作流编辑 UI 重写为状态机编辑器
  - 支持编辑 state id / action / slot / skill / message / next state
  - 支持添加/删除状态、重命名状态
