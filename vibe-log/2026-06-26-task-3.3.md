## 任务说明
实现 Skill 路由与前端选择入口：让用户可以通过 UI 或 `@风格` 快捷指令选择写作 Skill/风格，并把选择传递到 v4 Graph。

## 完成内容
- 新增 `src/comedy_agent/core/skill_router.py`：
  - 纯代码层路由，非模型判断。
  - 优先级：UI 显式选择 > 用户输入 `@提及` > State 中已保存选择 > 兜底 `my_skill`。
  - 支持别名映射（`@周奇墨` → `zhou_qimo` 等）。
  - 非写作类 Skill（如 `@话题`）不会被误判为写作 Skill。
- `src/comedy_agent/nodes/entry_node.py` 在意图分类后调用 `resolve_skill()`，将结果合并到返回字典，写入 `ComedyState`。
- 修改 `src/comedy_agent/api/routers/pro_v4.py`：
  - `ProChatV4Request` 增加 `skill_id` / `style` 字段。
  - 新会话时把选择写入初始 `ComedyState`。
  - 审阅恢复时使用 `Command(resume=..., update={...})` 同步更新 State。
- 修改 `src/comedy_agent/api/routers/pro.py` 的 `/pro/skills`：合并新版写作类 Skill（`metadata.kind == "standup"` 或已知风格 Skill）。
- 修改 `frontend/pro-b.html`：
  - 新增 `selectedSkillId` / `selectedStyle` 状态。
  - 写作团队下拉新增「写作风格」区域，展示可切换的风格 Skill。
  - 顶部槽位状态条下方显示当前选中风格徽章。
  - `runAgentTurn` 发送 `skill_id` / `style`。
- 新增 `tests/test_skill_router.py`，覆盖默认、显式、@提及、State 保留、未知回退、槽位忽略等场景。
